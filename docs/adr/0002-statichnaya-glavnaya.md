# Главная страница остаётся статической

Главная страница не обращается к API: она содержит только контент о сервисе
и основное действие, ведущее на страницу записи.

Причина: API-контракт и доменная модель ещё не определены. Подтягивать с
бэкенда, например, типы звонков, значит угадывать форму ответа до того, как
контракт спроектирован. Первое обращение к API появится в фиче, для которой
контракт уже будет продуман.

Первое касание API случится позже — это осознанно, а не заглушка, которую
забыли доделать.
