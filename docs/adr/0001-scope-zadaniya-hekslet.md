# Официальное задание Hexlet — источник истины по объёму

Объём проекта определяется официальным заданием Hexlet. Планы из `README.md`,
которые заданием не подтверждены — «Мои звонки», «Страница бронирования по
публичной ссылке», «Настройки профиля и часового пояса», — требованиями
не считаются и не реализуются автоматически.
